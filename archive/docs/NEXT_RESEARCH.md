## Возможные направления (приоритизированы)

### 1. Reconciliation методы (MinT, OLS)
**Идея:** Согласовать прогнозы между уровнями иерархии
- Прогноз top-down + bottom-up → оптимальная комбинация
- Библиотеки: `hts` (R), `hierarchicalforecast` (Python)
- **Шанс на улучшение:** Средний

### 2. Гибридный подход по категориям
**Идея:** Использовать разные модели для разных типов товаров
- Плодоовощи: отдельная модель (высокая волатильность)
- Тарифы/ЖКХ: детерминированные правила
- Остальное: Ridge baseline
- **Шанс на улучшение:** Высокий

### 3. Группировка по импортозависимости
**Идея:** Отдельные модели для импортных товаров (где курс USD может работать)
- Данные: `data/usd_correlations.csv` (766 товаров с корреляциями)
- Выделить товары с |corr| > 0.3
- **Шанс на улучшение:** Низкий (уже тестировали экзогенные)

### 4. BVAR на группах категорий
**Идея:** Байесовская VAR учитывает взаимосвязи между категориями
- Группы: Продовольственные, Непродовольственные, Услуги
- Преимущество: учёт cross-category spillovers
- **Шанс на улучшение:** Средний

### 5. Недельные данные для nowcasting
**Идея:** Использовать недельные цены для уточнения прогноза текущего месяца
- Данные: `data/weekly_prices.csv`
- MIDAS-модель уже частично реализована (`sirena_midas.py`)
- **Шанс на улучшение:** Высокий для краткосрочного прогноза
