## Алгоритм прогнозирования

```
1. Для каждого субкомпонента (36 шт):
   - Ridge модель с лагами [1, 2, 3, 12]
   - ETS сезонность (месячные средние)
   - Ансамбль: 30% Ridge + 70% ETS
   
2. Агрегация:
   - Взвешенная сумма по весам из справочника
   - ИПЦ = Σ(forecast_i × weight_i) / Σ(weight_i)
```
