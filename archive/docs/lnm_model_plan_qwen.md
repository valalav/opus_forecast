# План реализации модели Линейных Смешанных Моделей (LNM) - Qwen версия

## 1. Обзор существующей системы

Система **СИРЕНА-КБР** v4.7 предназначена для прогнозирования индекса потребительских цен (ИПЦ) в Кабардино-Балкарской Республике. В настоящее время используется ансамбль из 7 моделей:
- Ridge (40%), BVAR (20%), LightGBM (15%), Prophet (10%), SARIMA (5%), ETS (5%), EBM (5%)

Основной производительный показатель: Ridge с MAE 0.316

## 2. Анализ примера ЛМНР из методической документации

На основе файла "Пример кода лмнр.R" из папки metod, можно выделить следующие ключевые элементы:

### Структура модели:
- Использование сезонного сглаживания (X13/JDemetra)
- Компонентный анализ (продовольственные товары, непродовольственные товары, услуги)
- Веса компонент: продовольственные (43.123%), непродовольственные (37.063%), услуги (19.814%)
- Факторные переменные: USD, нефть, цены на промышленные товары, транспортные тарифы, зарплаты, кредитование
- Динамические лаги (L(ipc, 1), L(usd, 1))
- Фиктивные переменные для структурных изменений

### Ключевые функции:
- `dynlm` для линейных динамических моделей
- Сезонное сглаживание X13 с использованием RJDemetra
- ARIMAX модели с внешними регрессорами
- Комбинирование прогнозов компонентов

## 3. План реализации LNM модели для СИРЕНА-КБР

### Этап 1: Подготовка данных (неделя 1)
1.1. Создать класс-наследник `BaseForecaster` в файле `sirena/models/lnm.py`
1.2. Адаптировать текущие данные (`data/infl_kbr.csv`, `data/sa_fl.csv`) к формату для LNM
1.3. Реализовать импорт и преобразование сезонно-скорректированных данных
1.4. Подготовить внешние факторы (валютный курс, цены на нефть, ставки и др.)

### Этап 2: Реализация базового LNM (неделя 2)
2.1. Реализовать структуру смешанных эффектов:
- Фиксированные эффекты: тренд, сезонность, макроэкономические факторы
- Случайные эффекты: компоненты инфляции, региональные особенности
2.2. Использовать библиотеку `statsmodels` для LNM в Python
2.3. Реализовать функцию оценки параметров модели (REML или ML)
2.4. Добавить диагностику модели (тесты на гетероскедастичность, нормальность остатков)

### Этап 3: Интеграция факторов и сезонности (неделя 3)
3.1. Внедрить сезонное сглаживание через вызовы R скриптов или библиотек типа `seasonal`
3.2. Добавить фиктивные переменные для структурных изменений (2014-2015, 2022)
3.3. Ввести динамические лаги основных переменных (инфляция, валюта, цены)
3.4. Реализовать автоматический отбор факторов на основе AIC/BIC

### Этап 4: Прогнозирование и валидация (неделя 4)
4.1. Реализовать метод прогноза с учетом случайных эффектов
4.2. Добавить оценку неопределенности прогноза (доверительные интервалы)
4.3. Разработать бэктест для модели с оконной кросс-валидацией
4.4. Реализовать функцию сравнения с другими моделями по MAE, RMSE

### Этап 5: Интеграция с системой (неделя 5)
5.1. Добавить модель в `ModelRegistry`
5.2. Настроить веса ансамбля с учетом новой модели
5.3. Добавить в API и дашборд
5.4. Написать тесты для новой модели

## 5. Ключевые факторы и переменные

### 5.1. Зависимые переменные
- `ipc` - общий ИПЦ
- `ipc_prod`, `ipc_neprod`, `ipc_uslugi` - по компонентам

### 5.2. Фиксированные эффекты
- Лаги инфляции (L(ipc, 1), L(ipc, 2))
- Макроэкономические факторы (валюта, цены на нефть)
- Сезонные эффекты (месячные дамми)
- Структурные изменения (фиктивные переменные)

### 5.3. Случайные эффекты
- Компоненты инфляции (различные категории товаров)
- Региональные/временные эффекты
- Неучтенные факторы

## 7. Потенциальные проблемы и решения

### 7.1. Ограниченный объем данных
- Использование иерархического подхода (LNM позволяет эффективно обрабатывать ограниченные данные)
- Регуляризация случайных эффектов
- Байесовский подход через `MixedLM.from_formula` с приоритетами

### 7.2. Структурные изменения
- Динамическое обновление модели при обнаружении структурных изменений
- Использование скользящих окон для оценки параметров
- Адаптивные веса для различных временных периодов
