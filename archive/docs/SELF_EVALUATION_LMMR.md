### 1. Описание модели и предпосылок

**Спецификация:**
Модель представляет собой **динамическую регрессию на сезонно-скорректированных данных** (Seasonally Adjusted - SA).

*   **Источник SA данных:** Используются готовые SA данные из файла `sa_fl.csv`, что обеспечивает консистентность сезонной корректировки.
*   **Базовая модель:** Ridge регрессия (L2 регуляризация) с параметром `alpha=0.5`.
*   **Нормализация:** RobustScaler для устойчивости к выбросам.
*   **Исключение аномалий:** Outlier years (2010) исключаются из обучающей выборки.

**Признаки модели:**
1. **Авторегрессионные лаги SA:**
   - `y_sa_lag1` - лаг 1 месяц сезонно-скорректированной инфляции
   - `y_sa_lag2` - лаг 2 месяца

2. **Экзогенные переменные:**
   - `usd_lag1` - курс доллара (лаг 1 месяц)
   - `brent_lag1` - цена нефти Brent (лаг 1 месяц)

3. **Shock dummies** (6 переменных):
   - `is_shock_dec2014` - декабрь 2014 (валютный кризис)
   - `is_shock_jan2015` - январь 2015 (продолжение шока)
   - `is_shock_dec2014_jan2015` - комбинированный dummy
   - `is_tariff_jul` - июль (индексация тарифов ЖКХ, ежегодно)
   - `is_shock_mar2022` - март 2022 (санкционный шок)
   - `is_shock_apr2022` - апрель 2022 (продолжение шока)

**Алгоритм прогнозирования:**
1. Загрузка SA данных из `sa_fl.csv`
2. Расчет сезонных факторов методом усреднения по месяцам (исключая 2022 год)
3. Построение матрицы признаков с лагами и dummies
4. Обучение Ridge регрессии
5. Прогноз SA MoM
6. Применение сезонного фактора для получения финального MoM прогноза

**Корректность предпосылок:**
Модель основана на гибридном подходе, сочетающем:
- Готовые SA данные (устраняет риски некорректной сезонной декомпозиции)
- Ridge регуляризацию (предотвращает переобучение)
- Структурные shock dummies (учитывает экзогенные шоки)

Такой подход соответствует best practices в эконометрическом моделировании временных рядов.

### 2. Точность модели

**Период валидации:** Январь 2023 — Ноябрь 2025
**Метод оценки:** Expanding Window Cross-Validation

**Результаты:**

| Модель | MAE | Δ vs SARIMA | Статус |
| :--- | :--- | :--- | :--- |
| **LMMR Hybrid** | **0.310** | **−37.4%** | **🏆 ЛУЧШАЯ** |
| Ridge Baseline | 0.316 | −36.2% | Production |
| LMMR X13 (minimal) | 0.384 | −22.4% | Хорошая альтернатива |
| **SARIMA (Базовая модель)** | **0.495** | **—** | **Baseline** |
| LMMR (Gemini) | 0.810 | +63.6% | Не рекомендуется |
| LMMR Claude | 1.435 | +189.9% | Не рекомендуется |

**Сравнение с альтернативной моделью (SARIMA):**
В соответствии с требованиями Южного ГУ Банка России, модель LMMR Hybrid сравнивается с базовой моделью класса ARIMA.

*   **Базовая модель (SARIMA):**
    - MAE: **0.495 п.п.**
    - RMSE: **0.656 п.п.**
    - MAPE: 136.5%

*   **LMMR Hybrid:**
    - MAE: **0.310 п.п.** (улучшение на **37.4%**)
    - Используемые признаки: SA лаги (y_sa_lag1, y_sa_lag2) + экзогенные (usd_lag1, brent_lag1) + 6 shock dummies

**Вывод по точности:**
LMMR Hybrid демонстрирует **значительное превосходство над базовой моделью SARIMA** (снижение MAE на 37.4%). Модель показывает **лучшую точность среди всех LMMR вариантов** и даже превосходит базовую Ridge модель на 2.0%. Это подтверждает правильность выбора гибридного подхода с использованием готовых SA данных и shock dummies для учета структурных сдвигов.

**Устойчивость к выбросам:**

### 7. Направления совершенствования (опционально)

   - Текущие dummies выбраны вручную
   - Перспектива: алгоритмическое определение структурных сдвигов (Intervention Analysis)

### 9. Файл реализации

**Путь:** `sirena/models/lmmr_hybrid.py`

**Регистрация в ModelRegistry:**
```python
from sirena.models import ModelRegistry

model = ModelRegistry.get("lmmr_hybrid")
```

**Использование:**
```python
from sirena.models import LMMRHybridForecaster

model = LMMRHybridForecaster(alpha=0.5)
model.fit(df, target_col='Все товары и услуги')
forecast = model.forecast(horizon=12)
```
