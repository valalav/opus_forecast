# План реализации модели LMMR (Linear Mixed/Factor Model) - Gemini

## Контекст
В проекте `sirena` уже реализованы ML-модели (Ridge, LightGBM) и эконометрические модели (BVAR, SARIMA). Оригинальный скрипт R (`metod/Пример кода лмнр.R`) описывает подход "ЛММР" (Линейная Многофакторная Модель Регрессии), который по сути является **динамической регрессией на сезонно сглаженных данных (SA)** с последующим восстановлением сезонности.

Этот план предлагает адаптацию данного подхода под Python-стек `sirena` и доступные данные.

## 1. Концепция модели (LMMR)

**Тип модели:** Dynamic Linear Regression (ARDL) on Seasonally Adjusted Data.
**Целевая переменная:** `IPC_SA` (Индекс потребительских цен, сезонно сглаженный).

**Уравнение (примерное):**
$$ y_t^{SA} = \alpha + \beta_1 y_{t-1}^{SA} + \beta_2 USD_{t-1} + \beta_3 RealIncome_t + \beta_4 Credit_t + \sum \delta_i Dummies_i + \epsilon_t $$

Где:
*   $y_t^{SA}$ — сезонно сглаженная инфляция (MoM).
*   $USD_{t-1}$ — лаг курса доллара (pass-through effect).
*   $RealIncome, Credit$ — прокси спроса (из `inflation_data.csv`).
*   $Dummies$ — шоковые переменные (2014, 2022).

**Отличие от текущего Ridge:**
*   Текущий Ridge учится на "сырых" данных с сезонными dummy.
*   LMMR учится на *очищенных* от сезонности данных (SA), что позволяет лучше улавливать макроэкономические тренды, не "отвлекаясь" на шум сезонности. Сезонность накладывается *постфактум*.

### Этап 3: Восстановление сезонности
В R коде используется X13-ARIMA-SEATS для прогноза сезонных факторов. В Python `statsmodels` не имеет встроенного X13 прогнозатора (требует бинарник).
**Предлагаемое решение:**
1.  Использовать "Наивную сезонность": Сезонный коэффициент месяца $M$ равен среднему коэффициенту за этот месяц за последние 3 года.
2.  Или использовать `ETS` для прогноза самой сезонной компоненты (выделенной через `seasonal_decompose`).

### Этап 4: Прогноз драйверов (Scenario Generation)
Модель требует значений драйверов (USD, Доходы) на горизонте прогноза.
*   Для USD: использовать уже реализованный `USDForecaster` (v4.7).
*   Для остальных: использовать наивный прогноз (последнее значение) или тренд.

## 3. Сравнение с R-оригиналом
| Компонент | R (Original) | Python (Gemini Plan) | Причина |
|-----------|--------------|----------------------|---------|
| Модель | `dynlm` | `LinearRegression` / `ElasticNet` | Гибкость sklearn, регуляризация |
| Сезонность | JDemetra+ (X13) | `seasonal_decompose` + Naive/ETS | Сложность установки X13 в прод |
| Факторы | PPI, Freight | USD, Real Income, Credit | Отсутствие данных PPI в `inflation_data.csv` |
| Цикл | Рекурсивный (Loop) | Рекурсивный (Loop) | Необходимость для динамических моделей |

## 4. Критерии успеха
*   MAE на бэктесте (2023-2025) не хуже 0.40 (сравнимо с BVAR).
*   Корректная реакция на шок курса доллара (проверяется сценарным анализом).
*   Отсутствие "дребезга" прогноза (гладкость SA компоненты).
