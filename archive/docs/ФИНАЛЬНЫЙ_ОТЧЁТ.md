## Выводы

### 1. Достигнутый результат
- MAE снижен на 12.8% (с 0.3699 до 0.3224)
- КПЭ вырос с 76% до 82%
- 67 из 82 прогнозов попали в коридор ±0.5 п.п.

### 2. Ключевые факторы успеха
- Исключение аномальных периодов (2022, 2010) из обучения
- Адаптивная комбинация Ridge + ETS по месяцам
- Макроданные: курс USD и ставка RUONIA

### 3. Ограничения модели
- Март - проблемный месяц (MAE ~0.8 п.п.)
- 2022 год - высокая ошибка при тестировании
- Горизонт только 1 месяц

### 4. Рекомендации для дальнейшего улучшения
- Данные других регионов СКФО (кросс-региональные эффекты)
- Недельные цены для nowcasting внутри месяца
- Инфляционные ожидания населения
