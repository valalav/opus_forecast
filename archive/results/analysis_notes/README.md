# Analysis Notes Registry

This folder is the stable home for short scenario notes and working forecast
memory that should survive across agent sessions.

Before continuing a forecast discussion, check:

1. `analysis_index.csv` for the list of saved notes.
2. The linked Markdown note for assumptions, source data, and key numbers.
3. Any related artifact paths listed in the note.

Use this folder for compact analyses that are not full production packages:
tariff scenarios, gasoline/fuel sensitivity, weekly nowcast interpretation,
microcomponent overrides, and other forecast-control-point memos.

Do not scatter these notes across new ad-hoc folders without adding an entry to
`analysis_index.csv`.
