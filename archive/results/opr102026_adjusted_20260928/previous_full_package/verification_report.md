- Ridge_ProdProxy недоступна: локальный Torg в `data/raw/infostat.csv` заканчивается
  июлем. Проверенного августовского выпуска этого вспомогательного источника нет
  среди использованных входов; модель исключена, нули/экстраполяция факта не применяются.
- Micro_SM восстановлена на августовском RAW-экспорте штатными statsmodels scripts,
  новая отсечка добавлена к матрице с сохранением старых отсечек. Модель вспомогательная,
  в ансамбль не входит. Предыдущая матрица сохранена.
- Nowcast выключен для публикации 28 сентября: последние локальные weekly датированы
  31 августа. Их нельзя выдавать за актуальную сентябрьскую оценку. Этот источник не
  использован в экспертной центральной траектории или Ensemble.
- Все вкладки не переоценивались новым полным h=1/h=2/h=12 backtest. Архивные
  backtest-таблицы остались историческими; их дата 08.09.2026, а не новая проверка качества.
- Старые встроенные графики ОПР не пересоздавались; основной лист и его числа проверены.
  Новая проверенная визуализация — `forecast.png` / `forecast.html`.
- Условные надбавки издержек, ослабление инерции и тариф 2027 не являются
  статистически оценёнными причинными коэффициентами. Сценарии не confidence intervals.
- SA workbook, 1,28-ГБ Access и полные backups оставлены локально и исключены из Git;
  в репозитории сохраняются extracts, hashes и опубликованные результаты.

## Воспроизведение

Из корня репозитория, после проверки источников:

```bash
rtk proxy python3 scripts/import_sa_vintage.py 'data/raw/2026-08 ИПЦ с исключением сезонности (регионы).xlsx' --data-dir data
rtk proxy python3 scripts/process_accdb_update_2.py --release data/source_updates/20260928 --download
rtk proxy python3 scripts/process_accdb_update_2.py --release data/source_updates/20260928 --apply
```

Micro_SM обновляется штатными `run_statsmodels.py --horizon 16` и
`export_micro_test_matrix.py`; команда и происхождение сохранены в
`prior_forecast_audit.md`. Августовский столбец объединён с исторической матрицей
по Date, старые отсечки не удалены.

```bash
rtk proxy python3 archive/results/forecast_update_20260928/refresh_models.py
rtk proxy python3 archive/results/forecast_update_20260928/build_update.py
rtk proxy python3 archive/results/forecast_update_20260928/update_opr.py
rtk proxy python3 archive/results/forecast_update_20260928/verify_update.py
rtk proxy python3 scripts/generate_charts.py
rtk pytest -q tests/test_forecast.py tests/test_data_freshness.py
rtk proxy python3 archive/results/full_forecast_package_2026_2027/build_package.py --update-dir archive/results/forecast_update_20260928
```

Builder полного пакета по умолчанию следует `current_update.json`; прежняя жёстко
заданная траектория доступна только с `--historical`. Повторная обычная сборка
не должна возвращать старый прогноз 4,02%.
