## Воспроизведение

Существующий `scripts/process_accdb_update_2.py` получил согласованный маршрут обновления. Режим без `--apply` только проверяет candidate; production не меняется. `--download` проверяет свежий публичный архив, сохраняет его hash и заново извлекает таблицы. `--extract` повторно извлекает установленный release. Hash каждой таблицы связан с hash базы; чужие/измененные extracts отклоняются.

```bash
python3 scripts/process_accdb_update_2.py --release data/source_updates/2026-09-08_access_july --download --proxy data/raw/infostat.csv --proxy-manifest data/raw/infostat_source_manifest.json
python3 scripts/process_accdb_update_2.py --release data/source_updates/2026-09-08_access_july --proxy data/raw/infostat.csv --proxy-manifest data/raw/infostat_source_manifest.json --apply
python3 data/external/micro_cpi_region_export/scripts/build_rolling_micro_test_matrix.py --input data/external/micro_cpi_region_export/region_cpi_long.csv --metadata data/external/micro_cpi_region_export/metadata.json --out data/external/micro_cpi_region_export/micro_test_statsmodels.csv --config data/external/micro_cpi_region_export/config/model.yml --horizon 12
python3 scripts/precompute_forecasts.py
python3 scripts/generate_charts.py
python3 scripts/verify_all_tabs.py
```

Macro и SA имеют самостоятельные первоисточники. Их новый выпуск нужно проверить и импортировать отдельно; Access не содержит торговлю/промышленность и не гарантирует совпадения последней даты RAW и SA. CLI не заменяет обновление всех внешних классов данных и не является фоновым монитором публикаций.
