4. **Real-time benchmarks, multiple origins and evaluation of uncertainty.** Accepted with correction. h12 is one origin with twelve path targets (`backtest_framework.py:293–299`, `943–952`), not twelve independent twelve-month-ahead forecasts. Research factor documentation uses a different design (`docs/FACTOR_MODEL_RESEARCH.md:141–155`, N=100 per horizon), so its MAEs cannot be ranked against the archive without matching protocols. Existing Theil code (`1416–1422`) uses held-out actuals to construct the naive sequence and is not included in output; merely exposing it would be wrong for h2/h12. Generate each baseline from that origin's information. Evaluate horizon-specific intervals using empirical coverage plus interval/quantile scores, not +/- MAE labelled as a confidence interval. Select parameters/ensemble weights on earlier origins, reserve later origins untouched, quantify uncertainty with dependence-aware paired loss analysis. Thresholds must be chosen before the held-out run and tied to decision value.

6. **Nowcast vintage audit before calibrating/promoting the weekly signal.** Accept the research direction, reject immediate promotion of the existing calibration as already validated. Learn blend weights inside earlier training origins, use stable monthly core forecasts instead of all available models equally, and retain a release-aware fallback. Do not automatically force Nowcast into array h1: data-release gaps can make the current calendar month differ from the first monthly forecast date; use target month plus as-of timestamp. ## Research choices to defer

Agree with deferring new deep learning, large BVAR/DFM, switching regimes and unrestricted stacking until core correctness, availability-aware baselines and nested chronological model selection are in place. The reason is unidentified incremental value and limited reliable evaluation, not proof these families cannot work. Existing VAR/FAVAR and component models should remain controls or interpretable alternatives; compare forecast contributions and conditional scenario behavior separately. A simple horizon-specific regularized blend and direct-versus-recursive Ridge comparison are bounded next experiments after the gates. A weekly model is a distinct nowcast experiment with publication vintages; a good point forecast does not establish causal policy identification.
