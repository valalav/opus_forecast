## 🎯 О системе

**СИРЕНА-КБР** — это интеллектуальная система поддержки принятия решений для прогнозирования индекса потребительских цен (ИПЦ) в Кабардино-Балкарской Республике. Она объединяет эконометрические модели, машинное обучение и оперативный мониторинг цен в реальном времени.

### Ключевые возможности:

1.  **Nowcasting (Оперативный прогноз t+0):**
    *   Прогнозирует инфляцию *текущего месяца* на основе недельных данных по 11 000+ товарам.
    *   Использует модель **MIDAS** (Bridge Equation) для связки недельных цен с месячным ИПЦ.
    *   Показывает драйверы роста (топ товаров, толкающих инфляцию вверх).

2.  **Ансамблевый прогноз (t+12):**
    *   Синтезирует прогноз из трех независимых моделей для максимальной точность:
        *   **Ridge (60%):** Основной тренд, адаптивная сезонность.
        *   **BVAR (30%):** Байесовская модель, учитывает макро-связи (Курс USD, Ставка RUONIA).
        *   **SARIMA (10%):** Чистая инерция и сезонность.

3.  **Сценарное моделирование ("Что-если"):**
    *   Позволяет вручную менять траектории курса **USD** и **Ключевой ставки**.
    *   Оценивает влияние шоков (девальвации, неурожая) на инфляцию.

4.  **Межрегиональный анализ:**
    *   Находит регионы-опережающие индикаторы (кто растет раньше КБР?).
    *   Анализирует корреляции по конкретным товарам (например, цены на топливо в Калмыкии предсказывают цены в КБР).

## 🧠 Архитектура моделей

### 1. Ridge (Champion v2.4)
*   **Тип:** Линейная регрессия с L2-регуляризацией.
*   **Фичи:** Лаги (1, 2, 12), Сезонность (ETS), Компоненты (Food/NonFood/Services).
*   **Точность (MAE):** ~0.33 п.п.

### 2. BVAR (Bayesian VAR)
*   **Тип:** Векторная авторегрессия с Minnesota Prior (аналитическое решение).
*   **Фичи:** ИПЦ, Продукты, USD, RUONIA.
*   **Роль:** Улавливает макроэкономические шоки.

### 3. MIDAS (Nowcasting)
*   **Тип:** Регрессия разночастотных данных.
*   **Роль:** Использует внутримесячную динамику (недели) для уточнения прогноза на ближайший месяц.
