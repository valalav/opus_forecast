# 🌌 Opus Autopoiesis: Manifesto

> "The goal is not just to forecast the future, but to build a mind that understands it."

## Philosophy
This is no longer just a list of tasks. This is a blueprint for a **Self-Evolving Economic Intelligence**.
Use the `edge_lab` not as a sandbox, but as a **Cradle**.

## The Core Loop (Autopoiesis)
1.  **Observe:** Ingest raw data (Prices, News, Global Macro).
2.  **Hypothesize:** The `HypothesisAgent` generates theories (e.g., "Does Lithium pricing predict Service inflation?").
3.  **Experiment:** The `ResearchAgent` writes code to test the theory.
4.  **Integrate:** Successful models are automatically added to the Ensemble.
5.  **Evolve:** The System rewrites its own "constitution" (weights, architectures) based on performance.

## Structure
*   **Epoch 1 (Foundation):** Solidify the mathematical base (Seasonality, Regimes).
*   **Epoch 2 (Expansion):** Infinite Data Ingestion (News, Satellite, Global Indices).
*   **Epoch 3 (Cognition):** Semantic Analysis & Narrative Economics.
*   **Epoch 4 (Singularity):** Fully autonomous model generation and deployment.

**Rule Zero:** Every completed task must spawn at least two new questions. The PRD is not a checklist; it is a growing tree.
