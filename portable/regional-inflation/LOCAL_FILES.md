# Локальные источники данных

Для автоматического чтения файлов из папки рядом с HTML запустите `Start.cmd` (он вызывает `Start.ps1` в Windows PowerShell). Он открывает приложение на `http://127.0.0.1:8765/regional-inflation.html`; поле пути по умолчанию указывает на папку рядом с `Start.ps1` и допускает отдельный каталог источников. Порт можно изменить параметром `-Port`, каталог при запуске — параметром `-SourcePath`.

Без запуска сервера браузер не может сам просматривать произвольную папку. Используйте встроенный выбор папки, если браузер поддерживает File System Access API, или выберите требуемые файлы через системный диалог. В обоих режимах нужны региональный выпуск Excel с листом `db` (поля `mom` и `mom_sa`) либо `regional_indices.json`, и, при отдельном обновлении ставок, локальный `macro_rates.json` или `inflation_data.csv` со столбцами `Date`, `Ki`, `Ruonia`. Файл `macro_rates.json` имеет приоритет как отдельный пакет ставок; CSV используется как локальный резервный источник. Даты макроданных должны покрывать весь горизонт региональной истории; непокрытие и пустые ставки показываются как ошибка, значения не подставляются.

В папке, выбранной пользователем, приложение ищет только названные файлы. При наличии нескольких подходящих Excel-файлов выбирается последний по имени. RAW `mom` и SA `mom_sa` загружаются из одного выпуска и целиком заменяют текущую историю, без склейки винтажей. Публичное обновление Яндекс.Диска остаётся отдельной командой.

`Start.ps1` обслуживает только необходимые файлы приложения, разрешённые форматы данных и проксирует только две SOAP-операции ЦБ РФ: ключевая ставка и RUONIA. Сервер на TcpListener не использует HTTP.sys/URL ACL и слушает только `127.0.0.1`, выдаёт случайный токен на запуск и проверяет Origin/Host и токен запросов; API не является общим файловым сервером или произвольным HTTP-прокси. Завершите сервер `Ctrl+C`.

В браузерах, где `file://` не разрешает сетевой выбор папки, встроенный picker требует локального сервера. Пользовательский путь передаётся в приложение явно; обходов каталогов сервер не выполняет.

Если отдельного файла ставок нет, сохраняются ставки выбранного пакета с явным уведомлением; их можно обновить через блок ЦБ. Полнота ставок проверяется по фактическому периоду обучения. PowerShell-сервер проверен на Linux с PowerShell 7, Windows 5.1 отдельно не проверена.
