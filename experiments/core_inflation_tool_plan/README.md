# План проекта: инструмент анализа устойчивой инфляции КБР

Эта папка содержит проектный план для разработки независимого инструмента анализа устойчивой инфляции по региону. Папка намеренно размещена в `experiments/`, чтобы не смешивать планирование с production-кодом СИРЕНА-КБР.

## Контекст

Excel-инструмент расчета устойчивой инфляции показал критический риск качества данных: в сохраненной книге лист `ИПЦ исходный mom` совпадал с `ИПЦ исходный yoy`, из-за чего YoY-значения попадали в месячную аннуализацию. Подробный аудит сохранен в:

- `docs/reports/core_inflation_xlsm_audit_2026-05-27.md`

Новый инструмент должен быть независимым от проблемного состояния Excel-книги и должен явно проверять входные ряды, веса, уровни компонент и итоговые формулы.

## Файлы плана

- `PROJECT_PLAN.md` - продуктовый и технический план проекта.
- `METHODOLOGY.md` - методология показателей устойчивой инфляции.
- `CODEX_CLI_CORE_INFLATION_TOOL_GOAL.md` - длинный goal-файл для Codex CLI controller/subagents.

## Предлагаемый результат будущей разработки

Минимальный продукт должен уметь:

1. читать региональные CPI-ряды из существующих CSV;
2. рассчитывать несколько показателей устойчивой инфляции;
3. объяснять месячные скачки через вклад компонент;
4. выдавать диагностические проверки качества данных;
5. сохранять результаты в отдельную папку артефактов, не меняя production-данные.

## Границы

На этапе планирования ничего не меняется в:

- `data/`
- `sirena/`
- `scripts/`
- `assets/charts/`
- dashboard-коде

Будущую реализацию сначала вести в отдельной экспериментальной области и интегрировать в основной проект только после проверки.
