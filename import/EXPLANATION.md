# Как работает сезонное сглаживание в проекте

В этой папке собраны ключевые файлы, отвечающие за сезонную корректировку (Seasonal Adjustment) и анализ сезонности.

## Общая архитектура

Система разделена на два независимых направления:
1.  **Production (Корректировка данных):** Использует внешнюю программу **X-13-ARIMA-SEATS** (стандарт Бюро переписи населения США) для получения качественно сглаженных данных.
2.  **Research (Анализ данных):** Использует библиотеку **Statsmodels** (Python) для аналитики, построения графиков и проверки гипотез.

---

## 1. Production: Сглаживание через X-13

Этот механизм используется для подготовки данных перед подачей в модели прогнозирования.

### Ключевые файлы:

1.  **`x13.py` (Low-Level Driver)**
    *   **Роль:** "Драйвер" или адаптер.
    *   **Как работает:** 
        *   Находит бинарный файл X-13 в папке `bin/` (выбирает между Windows `.exe` и Linux версией).
        *   Создает временные файлы `.spc` (спецификации) и данные.
        *   Запускает процесс X-13.
        *   Реализует стратегию **"План А / План Б"**: сначала пытается автоматически подобрать модель (`automdl`), если не выходит — использует надежную модель "airline" `(0 1 1)(0 1 1)`.
        *   Парсит выходные файлы `.s11` (сглаженный ряд), `.s12` (тренд) и др. обратно в Pandas Series.
    
2.  **`seasonal_adjustment_x13.py` (High-Level Manager)**
    *   **Роль:** Управление процессом и кэширование.
    *   **Как работает:**
        *   Принимает DataFrame с исходными данными.
        *   **Кэширование:** Считает SHA256-хэш исходного файла данных. Если файл с таким хэшем уже есть в `data/cache/`, загружает готовый результат (экономит время).
        *   Если кэша нет: проходит по всем колонкам, вызывает `x13.py`, собирает результат.
        *   Сохраняет результат в кэш.

### Пример использования (из кода):

```python
from utils.seasonal_adjustment_x13 import perform_seasonal_adjustment
import pandas as pd

# Загрузка сырых данных
df_raw = pd.read_csv("data.csv")

# Вызов сглаживания (вернет DataFrame, где указанные колонки заменены на сглаженные)
df_sa = perform_seasonal_adjustment(df_raw, roles_to_adjust=['CPI', 'GDP'])
```

## 2. Research: Анализ сезонности (Statsmodels)

Этот инструмент используется аналитиками для понимания структуры ряда, но не для изменения данных, подаваемых в модели.

### Ключевой файл:

3.  **`seasonality_analyzer.py`**
    *   **Роль:** Аналитический инструмент.
    *   **Инструменты:** Использует `seasonal_decompose` и `STL` (Seasonal-Trend decomposition using LOESS) из библиотеки `statsmodels`.
    *   **Функции:**
        *   Строит графики декомпозиции (Тренд, Сезонность, Шум).
        *   Считает силу сезонности (от 0 до 1).
        *   Строит периодограмму (спектральный анализ) для поиска скрытых циклов.
        *   Дает текстовые рекомендации (например, "Рекомендуется SARIMA").

## 3. Скрипты и Документация

4.  **`analyze_seasonal_adjustment.py`**
    *   Скрипт для визуальной проверки качества сглаживания. Строит графики "До/После" и показывает коррелограммы (ACF), чтобы убедиться, что сезонность убрана.

5.  **`SEASONAL_ADJUSTMENT_GUIDE.md`**
    *   Подробная документация по переходу на новую версию (v2.0), описывающая мотивацию отказа от статичных файлов в пользу динамического расчета.

## Как запустить проверку

Чтобы увидеть, как это работает на практике, можно запустить аналитический скрипт из корня проекта:

```bash
python export/analyze_seasonal_adjustment.py mom
```
*(Где `mom` — имя колонки, например, инфляция месяц-к-месяцу)*
