# Dashboard & Reports Guide

## Обзор

Интерфейс системы СИРЕНА-КБР представлен двумя компонентами:
1. **Streamlit Dashboard** (интерактивный режим)
2. **HTML Отчеты** (статический режим для рассылки)

---

## 1. Streamlit Dashboard

Интерактивный веб-интерфейс для работы с моделями в реальном времени.

### Запуск и Доступ

- **URL**: `http://localhost:8503` (или IP сервера)
- **Порт**: `8503`
- **Команда запуска**:
  ```bash
  streamlit run dashboard.py --server.port 8503
  ```

### Описание Вкладок

1. **📈 Прогноз (Forecast)**
   - Основная рабочая панель.
   - Показывает прогноз ансамбля на 12 месяцев вперед.
   - Позволяет настраивать веса моделей вручную.
   - Таблица с вкладом каждой модели.

2. **🔧 Экзогенные (Exogenous)**
   - Ввод сценариев для макро-переменных:
     - Курс доллара (USD)
     - Ключевая ставка (Ki)
     - RUONIA
   - Влияет на прогнозы моделей BVAR, RidgeMacro, SubcomponentMulti.

3. **✅ Бэктест (Backtest)**
   - Сравнение исторической точности моделей (Line plot).
   - Метрики MAE/RMSE по всем моделям.

4. **🛠 Методология**
   - Техническая справка (содержимое `docs/MODELS.md`).

5. **🧠 История (Component Analysis)**
   - Декомпозиция инфляции по компонентам (Food, NonFood, Services).
   - Анализ вкладов (contribution analysis).

6. **🗺 Регионы**
   - Сравнительный анализ инфляции в КБР с другими регионами СКФО и РФ.

7. **🔒 Инсайдер**
   - Режим работы с *предварительными* данными (до официальной публикации Росстата).
   - Использует `data/inflation_data.csv` (insider input).

8. **🔍 EBM**
   - Детальная интерпретация модели Efficient Explainable Boosting.
   - Графики важности признаков (Global Explanations).

9. **📊 Бэктест h=1 (Главный КПЭ)**
   - Результаты Rolling Backtest на горизонте 1 месяц.
   - Метрика, по которой ранжируются модели в ансамбле.

10. **📊 Бэктест h=2**
    - Результаты для горизонта 2 месяца.

11. **📊 Бэктест h=12**
    - Проверка долгосрочной траектории (годовой прогноз).

## 2. HTML Отчеты

Статические файлы, генерируемые скриптом `scripts/generate_charts.py`. Используются для быстрой отправки руководству без доступа к серверу.

**Расположение**: `assets/charts/`

| Файл | Описание |
|------|----------|
| **[index.html](../assets/charts/index.html)** | **Главная страница** со всеми ссылками. |
| `forecasts.html` | График прогноза всех моделей. |
| `forecast_table.html` | **Таблица прогнозов** с весами моделей. |
| `backtest_h1_predictions.html` | Интерактивный график h=1 бэктеста. |
| `metrics_comparison.html` | Сравнение MAE моделей (Bar chart). |
| `ranking_heatmap.html` | Тепловая карта эффективности моделей. |

**Обновление отчетов:**
```bash
python3 scripts/generate_charts.py
```

## 3. Решение проблем

**В: Dashboard недоступен по 8503.**
О: Проверьте, запущен ли процесс:
```bash
ps aux | grep streamlit
```
Если нет — перезапустите (лучше в `tmux` или `screen`):
```bash
nohup streamlit run dashboard.py --server.port 8503 &
```

**В: Изменил код модели, но в дашборде старые данные.**
О: Сбросьте кэш Streamlit:
1. Нажмите в дашборде кнопку меню (три полоски) -> **Clear cache**.
2. Или нажмите **C** на клавиатуре.
