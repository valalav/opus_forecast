## 1. Обзор модели

**SubcomponentMultiForecaster v2.2** — мультимодельная bottom-up модель прогнозирования инфляции, которая:
- Прогнозирует **45 субкомпонентов ИПЦ** индивидуально
- Использует **оптимальную модель** для каждого субкомпонента
- **Агрегирует** прогнозы по официальным весам Росстата
- Применяет **volatility-adaptive гиперпараметры**

### Ключевые метрики (v2.2)

| Метрика | Значение |
|---------|----------|
| MAE (h=1, 2020-2025) | **0.274** |
| Улучшение vs v1.0 Baseline | **-14.4%** |
| 2022 MAE (шоковый год) | **0.578** (-24% vs baseline) |
| KPI Violations | **15.4%** |
| SIRENA Score | **~0.45** (лучший) |

## 2. Теоретическое обоснование

### 2.1 Почему bottom-up?

**Проблема top-down подхода:**
Прогнозирование общего ИПЦ напрямую игнорирует структурные различия между компонентами:
- Плодоовощи (std=7.3) и мясо (std=1.1) требуют разных подходов
- Услуги ЖКХ имеют детерминированную сезонность (тарифы)
- Импортные товары зависят от USD, продукты — нет

**Решение bottom-up:**
Каждый субкомпонент прогнозируется отдельно с учётом его специфики, затем агрегируется:

```
ИПЦ_forecast = Σ(w_i × forecast_i) / Σ(w_i)
```

где w_i — вес i-го субкомпонента в корзине.

### 2.2 Почему мультимодельный подход?

**Гипотеза:** Разные категории товаров имеют разную природу ценовой динамики.

| Тип категории | Характеристика | Оптимальная модель |
|---------------|----------------|-------------------|
| Стабильные | Низкая волатильность, авторегрессия | Ridge |
| Сезонные | Выраженные годовые паттерны | Prophet |
| Волатильные | Резкие скачки, нелинейность | NGBoost |
| Неопределённые | Смешанный паттерн | Voting (Ridge+Lasso) |

### 2.3 Теоретические основы выбора моделей

#### Ridge Regression (58% веса)
- **Применение:** Стабильные товары (мясо, молоко, одежда, техника)
- **Обоснование:**
  - L2-регуляризация предотвращает переобучение на ~150 точках
  - Линейная зависимость от лагов хорошо моделирует инерционную динамику
  - α=100 обеспечивает сильное сглаживание

#### Prophet (17% веса)
- **Применение:** Услуги с выраженной сезонностью (ЖКХ, образование, туризм)
- **Обоснование:**
  - Автоматическое выделение годовой сезонности
  - Адаптивный тренд с changepoints
  - Устойчивость к выбросам

#### NGBoost (6% веса)
- **Применение:** Волатильные товары (плодоовощи, телерадиотовары)
- **Обоснование:**
  - Probabilistic gradient boosting для улавливания нелинейностей
  - Естественные доверительные интервалы
  - Робастность к выбросам

#### Voting Regressor (19% веса)
- **Применение:** Категории без явного паттерна
- **Обоснование:**
  - Ансамбль Ridge + Lasso снижает variance
  - Lasso выполняет feature selection
  - Усреднение стабилизирует прогноз

## 3. Архитектура

### 3.1 Структура данных

```
data/raw/
├── sub_mom.csv          # MoM по 45 субкомпонентам (2010-2025)
├── subcomp_sprav.csv    # Справочник: код, название, компонент, вес
└── sub_weight.csv       # Веса субкомпонентов
```

### 3.2 Pipeline модели

```
┌─────────────────────────────────────────────────────────────────┐
│                    SubcomponentMultiForecaster                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  1. ЗАГРУЗКА ДАННЫХ                                             │
│     ├── sub_mom.csv → 45 временных рядов                        │
│     └── subcomp_sprav.csv → веса, названия                      │
│                                                                  │
│  2. ОБУЧЕНИЕ (для каждого субкомпонента)                        │
│     ├── Определить тип модели из OPTIMAL_MODELS                 │
│     ├── Создать признаки: L1, L2, L3, L6, L12, D1, MA3          │
│     └── Обучить соответствующую модель                          │
│                                                                  │
│  3. ПРОГНОЗ                                                      │
│     ├── Для каждого субкомпонента получить forecast_i           │
│     └── Агрегировать: ΣΣ(w_i × forecast_i) / Σ(w_i)             │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 3.3 Признаки для ML-моделей

| Признак | Описание |
|---------|----------|
| L1, L2, L3, L6, L12 | Лаги 1, 2, 3, 6, 12 месяцев |
| D1 | Первая разность (momentum) |
| MA3 | Скользящее среднее за 3 месяца |
| month_sin, month_cos | Сезонные признаки |

### 3.4 Распределение субкомпонентов по моделям

| Модель | Количество | Вес (%) | Ср. волатильность |
|--------|------------|---------|-------------------|
| Ridge | 24 | 58.1% | 1.77 |
| Voting | 11 | 18.9% | 1.52 |
| Prophet | 8 | 16.9% | 3.83 |
| NGBoost | 2 | 6.1% | 5.08 |

- **Экстремальная волатильность**: Std = 7.32 (в 6.5x выше среднего)
- **Сезонные скачки**: -10% в августе (урожай), +8% в январе
- **Нелинейная динамика**: погодные шоки, логистика

NGBoost лучше улавливает:
- Резкие переломы тренда
- Асимметричные распределения ошибок
- Хвостовые события

## 7. Рекомендации

### 7.1 Использование в production

```python
from sirena.models import SubcomponentMultiForecaster

# Инициализация
model = SubcomponentMultiForecaster(horizon=1)

# Обучение
model.fit(df)

# Прогноз на следующий месяц
prediction = model.predict(df, target_date)
print(f"Прогноз: {prediction['prediction']:.2f}")

# Траектория на 12 месяцев
trajectory = model.forecast(horizon=12)
```

### 7.2 Рекомендуемый вес в ансамбле

На основе SIRENA Score и стабильности:
- **Текущий вес:** ~20% (неявно через SIRENA)
- **Рекомендуемый вес:** **30-35%**

Обоснование:
- Лучший SIRENA Score (0.515)
- Стабильное улучшение на всех горизонтах
- Меньше KPI violations

### 7.3 Возможные улучшения

1. **Добавить макро-признаки** для USD-зависимых субкомпонентов (29, 54, 53)
2. **Оптимизировать гиперпараметры** Ridge (α) для каждого субкомпонента
3. **Тестировать новые модели** для волатильных категорий (XGBoost, CatBoost)
4. **Внедрить online-обновление** весов моделей на основе последних ошибок
