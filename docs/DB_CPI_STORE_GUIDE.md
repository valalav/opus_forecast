# db_cpi_store.accdb — Справочник и инструкция

> **Что это:** База данных Microsoft Access, содержащая месячные индексы потребительских цен (ИПЦ) по **всем субъектам Российской Федерации** с 2010 года по настоящее время (~192+ наблюдений).
>
> **Размер файла:** ~1.2 ГБ
>
> **Расположение:** `data/db_cpi_store.accdb`
>
> **Данные:** до **Января 2026** (обновлено 19 февраля 2026)

---

## 1. Структура базы данных

### Таблицы (11 таблиц)

| Таблица | Описание | Примерный объём |
|---------|----------|-----------------|
| `regions_names` | Справочник регионов (коды, названия) | ~121 строка |
| `data_indices` | Месячные индексы ИПЦ (MoM, YoY) по товарам/регионам | Миллионы строк |
| `data_price` | Средние потребительские цены | Миллионы строк |
| `data_seasonalised` | Сезонно скорректированные индексы | Миллионы строк |
| `data_weights` | Детальные веса товаров/услуг | ~50K строк |
| `weights` | Вертикальные/горизонтальные/полные веса | ~820K строк |
| `items_names` | Справочник товаров/услуг (код, название, Росстат) | ~1119 строк |
| `items_set` | Наборы товаров для расчётов | ~18K строк |
| `items_structure` | Иерархия товарных групп (parent/child) | ~1107 строк |
| `region_structure` | Иерархия регионов (округа → субъекты) | ~116 строк |

### 1.1. Таблица `regions_names`

Справочник кодов и названий регионов РФ.

| Столбец | Тип | Описание |
|---------|-----|----------|
| `Code` | Integer | Уникальный код региона (0 = РФ в целом) |
| `Name` | Text | Название субъекта РФ |

**Ключевые коды регионов (примеры):**

- `0` — Российская Федерация (агрегат)
- Остальные коды — субъекты РФ (всего ~79 регионов + округа)

### 1.2. Таблица `data_indices`

Основная таблица с данными ИПЦ. Каждая строка — один индекс цен по конкретному товару/услуге в конкретном регионе за конкретный месяц.

| Столбец | Тип | Описание | Пример |
|---------|-----|----------|--------|
| `Code` | Integer (AutoNumber) | Уникальный ключ строки | 1, 2, 3... |
| `Day` | DateTime | Дата (первый день месяца) | `01/15/10 00:00:00` |
| `Region_code` | Integer | Код региона (FK → `regions_names.Code`) | 0, 7, 42... |
| `Item_code` | Integer | Код товара/услуги в классификаторе Росстата | 1, 2, 3, 4, 33... |
| `MoM` | Double | Индекс «месяц к предыдущему месяцу» | 100.84 |
| `YoY` | Double | Индекс «к декабрю предыдущего года» (накопленная) | 108.5 |
| `Calc` | Integer/Flag | Флаг расчёта (техническое поле) | 0 или 1 |

### 1.3. Таблица `data_price`

Средние потребительские цены в рублях. Структура аналогична `data_indices`.

| Столбец | Тип | Описание |
|---------|-----|----------|
| `Code` | Integer | Уникальный ключ |
| `Day` | DateTime | Дата (1-й день месяца) |
| `Region_code` | Integer | Код региона |
| `Item_code` | Integer | Код товара |
| `Price` | Double | Средняя цена (руб.) |

### 1.4. Таблица `data_seasonalised`

Сезонно скорректированные индексы ИПЦ. Структура аналогична `data_indices`.

| Столбец | Тип | Описание |
|---------|-----|----------|
| `Code` | Integer | Уникальный ключ |
| `Day` | DateTime | Дата |
| `Region_code` | Integer | Код региона |
| `Item_code` | Integer | Код товара |
| `MoM` | Double | Сезонно скорр. MoM |
| `YoY` | Double | Сезонно скорр. YoY |

### 1.5. Таблица `weights`

Веса товарных позиций в потребительской корзине. Основная таблица весов.

| Столбец | Тип | Описание |
|---------|-----|----------|
| `Code` | Integer | Уникальный ключ |
| `Day` | DateTime | Дата (обычно январь) |
| `Region_code` | Integer | Код региона |
| `Item_code` | Integer | Код товара |
| `Weight_horizontal` | Double | Горизонтальный вес |
| `Weight_vertical` | Double | Вертикальный вес (доля в корзине) |
| `Weight_gross` | Double | Полный (гросс) вес |

> **Важно:** `Weight_vertical` — это доля товара/группы в общей корзине ИПЦ. Например, для КБР (Январь 2026): Прод=39.86%, Непрод=36.38%, Услуги=23.76%.

### 1.6. Таблица `data_weights`

Дополнительная таблица с детальными весами. Содержит исторические данные весов.

### 1.7. Таблица `items_names`

Справочник товаров и услуг.

| Столбец | Тип | Описание |
|---------|-----|----------|
| `Item_code` | Integer | Код товара |
| `Name` | Text | Название товара/услуги |
| `Rosstat_code` | Text | Код по классификатору Росстата |

### 1.8. Таблица `items_structure`

Иерархическая структура товарных групп (parent → child).

| Столбец | Тип | Описание |
|---------|-----|----------|

### 1.9. Таблица `items_set`

Наборы товаров для различных расчётов.

### 1.10. Таблица `region_structure`

Иерархия регионов (федеральные округа → субъекты РФ).

| Столбец | Тип | Описание |
|---------|-----|----------|
| `Region_code` | Integer | Код региона (ребёнок) |
| `Parent_code` | Integer | Код округа (родитель) |

### 1.11. Таблица `z_max_day`

Служебная таблица с датой последнего обновления каждой основной таблицы.

| Столбец | Тип | Описание |
|---------|-----|----------|
| `Table_name` | Text | Имя таблицы |
| `Max_day` | DateTime | Последняя дата данных |

### Формат дат

Даты хранятся в формате `MM/DD/YY HH:MM:SS` (при экспорте через `mdb-export`).

**Преобразование в Python:**

```python
pd.to_datetime(df['Day'], format='%m/%d/%y %H:%M:%S')
```

### Кодировка значений MoM и YoY

- **MoM = 100.00** — цены не изменились (0%)
- **MoM = 101.50** — рост на +1.5%
- **MoM = 98.20** — снижение на -1.8%
- **YoY** — аналогично, но накопленный рост с декабря предыдущего года

## 3. Инструкция по извлечению данных

### 3.1. Инструмент: mdbtools (Linux)

База читается утилитами `mdbtools` (пакет для чтения .mdb/.accdb на Linux).

**Установка:**

```bash
sudo apt install mdbtools
```

**Доступные команды:**

```bash
mdb-tables -1 data/db_cpi_store.accdb     # Список таблиц
mdb-schema data/db_cpi_store.accdb         # Полная схема SQL
mdb-schema --table data_indices data/db_cpi_store.accdb  # Схема таблицы
mdb-export data/db_cpi_store.accdb regions_names  # Экспорт в CSV
mdb-export data/db_cpi_store.accdb data_indices   # Экспорт в CSV (ОГРОМНЫЙ!)
```

> [!WARNING]
> **Файл весит 1.2 ГБ!** Экспорт таблицы `data_indices` целиком через `mdb-export` занимает **10-30 минут** и генерирует файл в несколько гигабайт CSV. Используйте потоковую обработку (см. ниже).

### 3.2. Потоковое извлечение с фильтрацией (рекомендуемый способ)

**Python-скрипт для извлечения данных конкретных товарных групп:**

```python
import pandas as pd
import subprocess

DB_PATH = "data/db_cpi_store.accdb"
TABLE = "data_indices"

# Целевые Item_code (агрегаты)
target_items = {1, 2, 3, 4, 33}  # Все, Непрод, Прод, Услуги, Плодоовощи

# Запускаем mdb-export как стрим
cmd = ["mdb-export", DB_PATH, TABLE]
process = subprocess.Popen(cmd, stdout=subprocess.PIPE)

chunks = []
for chunk in pd.read_csv(process.stdout, chunksize=100_000):
    filtered = chunk[chunk['Item_code'].isin(target_items)]
    if not filtered.empty:
        chunks.append(filtered[['Day', 'Region_code', 'Item_code', 'MoM']])

df = pd.concat(chunks)

# Преобразование дат
df['Date'] = pd.to_datetime(df['Day'], format='%m/%d/%y %H:%M:%S', errors='coerce')
df = df.dropna(subset=['Date'])

df.to_csv('data/output.csv', index=False)
print(f"Сохранено {len(df)} строк")
```

### 3.3. Извлечение данных одного региона

```python
import pandas as pd
import subprocess

DB_PATH = "data/db_cpi_store.accdb"

# Шаг 1: Узнать код региона из справочника
regions_csv = subprocess.run(
    ["mdb-export", DB_PATH, "regions_names"],
    capture_output=True, text=True
).stdout
regions = pd.read_csv(pd.io.common.StringIO(regions_csv))
print(regions.to_string())
# Найти нужный код, например КБР

# Шаг 2: Потоковый экспорт с фильтрацией по Region_code
KBR_CODE = 7  # ПРИМЕР — уточнить по справочнику!

cmd = ["mdb-export", DB_PATH, "data_indices"]
process = subprocess.Popen(cmd, stdout=subprocess.PIPE)

chunks = []
for chunk in pd.read_csv(process.stdout, chunksize=100_000):
    filtered = chunk[chunk['Region_code'] == KBR_CODE]
    if not filtered.empty:
        chunks.append(filtered)

df = pd.concat(chunks)
df['Date'] = pd.to_datetime(df['Day'], format='%m/%d/%y %H:%M:%S', errors='coerce')
df.to_csv('data/infl_kbr_full.csv', index=False)
print(f"КБР: {len(df)} строк")
```

### 3.4. Извлечение на Windows (pyodbc)

```python
import pyodbc
import pandas as pd

conn = pyodbc.connect(
    r'DRIVER={Microsoft Access Driver (*.mdb, *.accdb)};'
    r'DBQ=C:\path\to\db_cpi_store.accdb;'
)

# Все данные по КБР
query = """
SELECT Day, Item_code, MoM, YoY
FROM data_indices
WHERE Region_code = 7
ORDER BY Day, Item_code
"""

df = pd.read_sql(query, conn)
df.to_csv('infl_kbr.csv', sep=';', decimal=',', index=False, encoding='utf-8-sig')
conn.close()
```

## 5. Важные особенности

### 5.1. Размер и производительность

| Метрика | Значение |
|---------|----------|
| Размер файла | ~1.2 ГБ |
| Таблица `data_indices` | Миллионы строк |

| Временной охват | 2010 — 2025 (192+ наблюдений) |
| Частота | Помесячно |

### 5.2. Gotchas (подводные камни)

1. **Не открывать целиком в pandas!** — файл слишком большой. Только потоковая обработка.
2. **Формат дат** — `MM/DD/YY HH:MM:SS`, не путать с `DD.MM.YYYY`.
3. **MoM — это индекс, не процент!** 100.84 = рост на 0.84%, НЕ на 100.84%.
4. **Region_code = 0** — обычно агрегат по РФ, не отдельный регион.
5. **Кодировка мешает `mdb-tables`** — на большом файле команда может работать очень долго (минуты). Не отменяйте — дождитесь.
6. **Item_code может отличаться** от кодов в других справочниках (например, `micro_sprav.csv` использует свою нумерацию).
