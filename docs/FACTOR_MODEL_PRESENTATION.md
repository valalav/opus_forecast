# Factor Model Presentation Notes

Дата: 2026-06-09

## Название модели

**Стационарная блочная FAVAR-модель денежно-компонентных факторов**

Короткое англоязычное название для технических материалов:
`Stationary Block FAVAR`.

Реализация в проекте:

- модель: `sirena/models/stationary_block_favar.py`
- registry key: `stationary_block_favar`
- исследовательский прогон:
  `experiments/factor_model_research/runs/stationary_block_favar/`

## Короткое описание

Модель выделяет два интерпретируемых скрытых фактора из наблюдаемых рядов:
компонентный фактор региональной инфляции и денежно-финансовый фактор. Затем
эти факторы вместе с инфляцией включаются в компактную динамическую
FAVAR-систему, которая прогнозирует месячный прирост ИПЦ с учетом инерции,
сезонности и лагового влияния факторов.

## Экономическая логика

Компонентный фактор агрегирует совместное движение продовольственных товаров,
непродовольственных товаров и услуг. Экономически он отражает внутреннюю
структуру региональной инфляции: продовольственные шоки, инерцию услуг,
перенос давления между группами товаров и общую ценовую среду.

Денежно-финансовый фактор агрегирует курс, ключевую ставку и изменение спреда
между RUONIA и ключевой ставкой. Экономически он отражает импортируемое
ценовое давление, стоимость денег и краткосрочную жесткость денежно-финансовых
условий.

PCA используется не как черный ящик, а как способ сжать несколько шумных и
коррелированных рядов в компактные факторы. Это снижает риск переобучения на
короткой региональной месячной выборке.

FAVAR-часть задает динамику: текущая инфляция зависит от собственной инерции и
лаговых значений скрытых факторов. Сезонность учитывается только по обучающей
выборке, поэтому будущая информация не подмешивается в backtest.

## Почему это реальная факторная модель

Модель не является обычной регрессией с макропеременными. В ней есть ключевые
элементы факторного подхода:

- скрытые факторы строятся из набора наблюдаемых рядов через PCA;
- факторы разделены на экономически интерпретируемые блоки;
- прогноз строится не по отдельным исходным рядам, а по компактному факторному
  представлению;
- факторы включены в динамическую FAVAR-систему;
- все преобразования выполняются leakage-safe: только на данных, доступных на
  момент прогноза.

Корректная формулировка для отчета:

> Построена прикладная блочная FAVAR-модель: скрытые факторы извлекаются из
> компонент инфляции и денежно-финансовых рядов, после чего используются в
> компактной динамической системе для прогноза регионального ИПЦ.

## Диагностический статус

Выбранная спецификация: `StationaryBlockFAVAR_dspread_l1`.

Основные метрики rolling backtest:

| Горизонт | N | MAE | RMSE | Доля ошибок <= 0.5 п.п. |
| ---: | ---: | ---: | ---: | ---: |
| h=1 | 100 | 0.378 | 0.619 | 77.0% |
| h=2 | 100 | 0.418 | 0.704 | 75.0% |
| h=12 | 100 | 0.432 | 0.715 | 71.0% |

Эконометрические проверки:

| Блок проверки | Статус |
| --- | --- |
| ADF/KPSS по transformed inputs | пройдено |
| Zivot-Andrews с одним структурным сдвигом | пройдено |
| Ljung-Box по остаткам уравнений | пройдено |
| Breusch-Godfrey по динамическим уравнениям | пройдено |
| ARCH-LM по остаткам | пройдено |
| bias/t-test по остаткам | пройдено |
| rolling forecast-error autocorrelation | пройдено |
| rolling forecast-error ARCH | пройдено |
| Jarque-Bera normality | expected warning |

Jarque-Bera отвергает нормальность остатков. Это не скрывается: для
региональной инфляции с шоками и тяжелыми хвостами это ожидаемое ограничение.
Поэтому модель использует Huber-оценивание и не заявляется как модель с
гауссовскими ошибками.

Phillips-Perron не был включен в сохраненный прогон, потому что в окружении не
был установлен optional-пакет `arch`. Для усиления отчета можно дополнительно
установить `arch`, прогнать PP-тест и приложить таблицу к блоку стационарности.

## Как позиционировать

Основная роль модели: обязательная факторная линия и эконометрически
защищаемый benchmark/control signal.

Не следует позиционировать ее как замену production ensemble: по h=1 она слабее
лучших production/subcomponent моделей. Ее ценность в другом: она
интерпретируема, построена по факторной логике, проходит hard diagnostics по
стационарности и остаткам, и может использоваться как независимый контрольный
сигнал.

Короткая фраза для доклада:

> Мы построили не только VAR, но и отдельную факторную модель. Это
> стационарная блочная FAVAR: она извлекает скрытые компонентный и
> денежно-финансовый факторы, затем прогнозирует ИПЦ через компактную
> динамическую систему. По точности она уступает лучшим прикладным моделям, но
> является полноценной факторной спецификацией и проходит основные
> эконометрические проверки.

## Возможное развитие

Перспективное направление после факторной линии - взвешенная гибридная
bottom-up модель:

- общий ИПЦ раскладывается на субкомпоненты с официальными весами;
- для стабильных субкомпонентов используется простая регуляризованная или
  сезонная модель;
- для волатильных и весомых субкомпонентов используется отдельная
  микрокомпонентная модель;
- итоговый прогноз агрегируется через веса;
- верхнеуровневые модели, включая FAVAR/VAR, используются как контроль или
  корректирующий слой.

Такой подход экономически оправдан, потому что ошибка по крупной и волатильной
субкомпоненте дает непропорционально большой вклад в ошибку общего ИПЦ.
