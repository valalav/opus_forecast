## Цель исследования

Выявить причины расхождения между публикуемым Росстатом субкомпонентом "Плодоовощи" (код 33) и взвешенной суммой 21 микрокомпонента по данным 2024-2025 годов.

---

## Постановка проблемы

### Наблюдаемое расхождение

При агрегации 21 микрокомпонента плодоовощей по официальным весам Росстата результат **не совпадает** с публикуемым субкомпонентом 33:

```
sub_mom[33] ≠ Σ(weight_i × micro_mom_i) / Σ(weight_i)
```

### Масштаб расхождения (КБР, 2016-2025)

| Метрика | Значение |
|---------|----------|
| Mean Absolute Difference | 1.93 п.п. |
| Корреляция рядов | 0.91 |
| Max расхождение | до 5 п.п. |

### Региональная специфика

Анализ 106 регионов показал неравномерность расхождения:

| Регион | MAD | Позиция |
|--------|-----|---------|
| РФ в целом | 1.05 | 19/106 |
| КБР | 1.93 | 88/106 |
| Лучший регион | 0.43 | 1/106 |
| Худший регион | 3.18 | 106/106 |

## Методика анализа

### Шаг 1: Подготовка данных
```
1.1. Выгрузить sub_mom[33] по всем регионам за 2024-2025
1.2. Выгрузить micro_mom[21 код] по всем регионам за 2024-2025
1.3. Выгрузить веса из справочника
1.4. Проверить полноту данных (нет ли пропусков)
```

### Шаг 2: Воспроизведение агрегации
```
2.1. Для каждого региона и месяца:
     agg = Σ(weight_i × (micro_mom_i - 100)) / Σ(weight_i) + 100
2.2. Сравнить agg с sub_mom[33]
2.3. Рассчитать MAD по регионам
```

### Шаг 3: Анализ расхождений
```
3.1. Построить распределение MAD по регионам
3.2. Выделить кластеры: "сходится" (MAD < 0.5) vs "не сходится" (MAD > 1.5)
3.3. Проанализировать характеристики кластеров
```

     - Подобрать веса методом МНК для идеальной сходимости

## РЕЗУЛЬТАТЫ ИССЛЕДОВАНИЯ

### Найденная формула агрегации

**Росстат использует ЦЕПНЫЕ ИНДЕКСЫ к декабрю предыдущего года:**

```python
# Для каждого месяца t:
Cum_i(t) = Cum_i(t-1) × (1 + MoM_i(t)/100)  # Cum_i(0) = 100 в январе
Agg_Cum(t) = Σ(Cum_i(t) × W_i) / Σ(W_i)
Sub_MoM(t) = (Agg_Cum(t) / Agg_Cum(t-1) - 1) × 100
```

### Верификация формулы

| Год | MAD (п.п.) | Товаров | Комментарий |
|-----|------------|---------|-------------|
| **2025** | **0.003** | 21 | **ИДЕАЛЬНОЕ СОВПАДЕНИЕ** |
| 2024 | 0.224 | 20 | Нет перца |
| 2023 | 0.416 | 20 | |
| 2022 | 0.471 | 20 | |
| 2021 | 0.307 | 17 | |

### Региональная специфика

| Регион | MAD | Позиция | Интерпретация |
|--------|-----|---------|---------------|
| РФ в целом | 1.05 | 19/106 | Хорошая сходимость |
| КБР | 1.93 | 88/106 | Плохая сходимость |
| Лучший | 0.43 | 1/106 | Почти идеально |
| Худший | 3.18 | 106/106 | Сильное расхождение |

### Влияние на прогнозные модели

| Метод | MAE (sub 33) |
|-------|--------------|
| **MicroPlodovoshchi v2.0** (цепные индексы) | **1.756 pp** |
| NGBoost (прямой прогноз) | 4.047 pp |
| Ridge (прямой прогноз) | 3.783 pp |

**Вывод:** Микрокомпонентная модель с цепными индексами в 2+ раза лучше для прогноза субкомпонента 33.

### Рекомендации

1. **Для КБР:** Использовать прямой прогноз субкомпонента (расхождение данных)
2. **Для РФ:** Можно использовать микрокомпонентный подход (данные сходятся)
3. **Для nowcasting:** Формула цепных индексов критична для корректной агрегации
