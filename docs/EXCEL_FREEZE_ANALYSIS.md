# Спецификация: Анализ заморозки цен потребительской корзины в среде MS Excel

> **Цель:** Полностью воспроизвести логику расчета индексов PSI, FDI и пружинного эффекта для всероссийской базы инфляции исключительно средствами MS Excel (Power Query, DAX, макросы), без использования Python, Pandas или внешних БД.

Эта спецификация выступает подробным Техническим Заданием (ТЗ) для аналитика или разработчика Excel.

---

## 1. Входные данные

Ожидается, что на входе имеется плоская таблица (или набор файлов, агрегируемых через Power Query из папки) со следующей минимальной структурой:

| Поле | Тип данных | Описание |
|------|-----------|----------|
| `Date` | Дата | Месяц отчета (например, 01.01.2024) |
| `Region` | Текст | Название или код субъекта РФ / вся страна |
| `Item_Code`| Текст / Число | Уникальный код товара/услуги |
| `Item_Name`| Текст | Наименование товара или услуги |
| `MoM` | Десятичное | Месячный индекс цен (к предыдущему месяцу). **100.0 = цена не изменилась** |
| `Weight` | Десятичное | Вес товара в корзине (доля от 1.0 или 100%) |

---

## 2. Глоссарий и целевые метрики

1. **PSI (Индекс жесткости цен)** — Доля месяцев в году, когда цена на товар не менялась (`MoM = 100.0`).
2. **Серия заморозки (Freeze Streak)** — Количество месяцев подряд, в течение которых `MoM = 100.0`.
3. **Пружинный эффект (Spring Effect)** — Размер скачка инфляции (`MoM` минус 100.0) в **первый месяц изменения** цены после завершения "Серии заморозки".
4. **FDI (Freeze Diffusion Index, Доля активной базы)** — Доля веса потребительской корзины (в %), цены на которую в конкретный месяц **заморожены** (`MoM = 100.0`) или, наоборот, **активны** (`MoM <> 100.0`).

---

## 3. Архитектура решения (Pipeline в Excel)

Решение строится на базе **Power Query (PQ)** для ETL-трансформаций и вычисления рядов, и **Power Pivot (DAX)** для агрегации метрик.

### ШАГ 1: Извлечение и базовая чистка (Power Query)
1. Подключиться к источнику с данными (книга Excel или папка с CSV/XLSX).
2. Очистить данные от пустых строк и возможных ошибок (NaN/Null).
3. Привести колонку `MoM` к типу Decimal (с разделителем точка или запятая, в зависимости от локали ОС Windows).
4. **Добавить флаг заморозки:**
   - Создать пользовательский столбец `IsFrozen`: 
     ```powerquery
     if [MoM] = 100.0 then 1 else 0
     ```

### ШАГ 2: Вычисление "Индекса жесткости цен" (PSI)
Самый простой шаг, можно сделать сводной таблицей (Pivot).
- **В Power Query:** Извлекаем из `Date` столбец `Year`.
- **В Сводной таблице / DAX:**
  - Строки: `Region`, `Item_Name`.
  - Столбцы: `Year`.
  - Значения: Average (среднее) для столбца `IsFrozen`.
  - *Итог:* Наглядная матрица: у каких товаров PSI составляет 80-99% (рекордные заморозки), а у каких < 1% (свежие овощи).

### ШАГ 3: Вычисление "Пружинного эффекта" (Сложный ETL)
Это ключевая часть задачи, так как требует анализа оконных функций, которых в Power Query по умолчанию нет.

**Алгоритм для Power Query:**
1. Отсортировать данные строго по: `Region`, `Item_Code`, `Date` (по возрастанию).
2. Сгруппировать по `[Region, Item_Code]`, выбрав агрегацию "Все строки" (создаст столбец с таблицами/списками).
3. Написать кастомную функцию (или развернуть M-скрипт) внутри групп, которая проходит по отсортированному столбцу `IsFrozen` и присваивает уникальный номер "Острова" (Island/Group ID) каждой непрерывной серии стагнации или изменения.
   - *Подсказка для аналитика:* Добавление индекса (Index_0) и сдвига (Index_0 + 1) через объединение таблицы самой с собой позволяет найти моменты, когда `IsFrozen` меняет значение с 1 на 0. Добавив Cumulative Sum, мы получаем уникальный ID каждой серии длительной заморозки.
4. Сгруппировать по полученному `Group_ID`, посчитав `Count` (Длительность заморозки, кол-во месяцев).
5. Найти для каждой записи `Group_ID` значение `MoM` **в следующем периоде** (месяце сразу после разморозки).
6. Вывести финальную агрегацию:
   - Ось X: Длительность заморозки (градации: 1-2 мес, 3-5 мес, 6-11 мес, 12-23 мес, 24+ мес).
   - Ось Y: Среднее или медианное отклонение разморозки (`MoM` - 100).

### ШАГ 4: Индекс FDI (Доля активной базы / Диффузия)
Показывает, какая часть экономики в отчетный месяц реально инфлирует.

Для каждого `Date` и `Region`:
1. **Общий вес корзины (Total_Weight)** = `SUM(Weight)`
2. **Замороженный вес (Frozen_Weight)** = `SUM(Weight)` с условием `IsFrozen = 1`
3. **Активный вес (Active_Weight)** = `SUM(Weight)` с условием `IsFrozen = 0`
4. **FDI_Score** = `Frozen_Weight / Total_Weight`

*Реализация DAX:*
```dax
FDI_Score := 
CALCULATE( SUM('Data'[Weight]), 'Data'[IsFrozen] = 1 ) 
/ 
SUM('Data'[Weight])
```

## 4. Требования к производительности в Excel

1. **Отключение шагов загрузки:** Так как данных много, промежуточные вспомогательные шаги или таблицы из Power Query необходимо оставлять как "Только создание подключения" (Create Connection Only) и снимать галочку с "Добавить в модель данных", кроме Финальных 3-х витрин.
2. **Три финальные витрины для выгрузки в Листы Excel:**
   - Таблица 1: `PSI_Yearly` (PSI по годам и регионам).
   - Таблица 2: `Spring_Effect_Stats` (Длительность заморозки -> Средний/Медианный скачок вверх/вниз).
   - Таблица 3: `FDI_TimeSeries` (Таймсерия % замороженной и % активной корзины по месяцам).
3. Если "Пружинный эффект" внутри Power Query (Шаг 3) начнет сильно "тормозить", логику перехода состояния и подсчета непрерывных серий рекомендуется перенести на макросы (VBA), которые пробегутся по отсортированному листу сверху-вниз за долю секунды, используя массивы в памяти (`Variant()`).

## 5. Выводы для принятия макро-решений
Полученные отчеты позволят на Windows-клиенте мгновенно ответить на вопросы:
- Какие конкретные услуги являются самыми жесткими в регионах?
- Стоит ли ожидать инфляционных "всплесков" в июле, если серия удержания цен длилась больше года?
- Если общий MoM инфляции 100.5%, но 80% корзины "спит", какова инфляция в оставшихся 20%? (Обычно она в разы выше).
