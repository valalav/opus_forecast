## Введение

Система **СИРЕНА-КБР** (СИстема Регионального Экономического Новокастирования и Анализа) предназначена для прогнозирования индекса потребительских цен (ИПЦ) в Кабардино-Балкарской Республике.

### Что прогнозирует система?

Система прогнозирует **месячную инфляцию** (MoM — month-over-month) для ИПЦ "Все товары и услуги".

- **Единицы измерения:** Процентные пункты (п.п.)
- **Горизонт прогноза:** 1-12 месяцев вперед
- **Обновление:** Ежемесячно (после публикации официальных данных Росстата)

### Источники данных

- **Росстат:** Официальная статистика по КБР и РФ
- **ЦБ РФ:** Ключевая ставка, RUONIA, курс доллара
- **Международные рынки:** Нефть Brent (как экзогенный фактор)
- **Недельные цены:** 155 товаров-представителей (Rosstat)

## Основные понятия

### Ансамбль моделей

Ансамбль — это комбинация прогнозов от 19+ разных моделей. Каждая модель использует свои подходы и данные.

**Зачем нужен ансамбль?**
- Уменьшает риск ошибки одной модели
- Стабилизирует прогноз
- Объединяет сильные стороны разных подходов

**Пример:** Если Ridge предсказывает +0.4%, а Subcomp_Multi +0.6%, ансамбль покажет +0.5%.

### Горизонты прогноза

| Горизонт | Описание | Использование |
|----------|----------|--------------|
| **h=1** | 1 месяц вперед | **Главный КПЭ** — для оперативных решений |
| **h=2** | 2 месяца вперед | Для планирования на квартал |
| **h=12** | 12 месяцев вперед | Годовая траектория — для бюджетирования |

### MAE (Mean Absolute Error)

Средняя абсолютная ошибка — основная метрика качества.

- **MAE = 0.3** означает, что в среднем прогноз ошибается на 0.3 п.п.
- **Меньше MAE = лучше модель**
- **Целевой уровень:** MAE < 0.5 (KPI системы)

### KPI Violations

Нарушения KPI — это месяцы, когда ошибка превысила 0.5 п.п.

- **Цель:** Минимум нарушений (менее 2-3 в год)
- **Хорошо:** < 10% месяцев с нарушениями
- **Плохо:** > 25% месяцев с нарушениями

## Интерпретация прогнозов

### Уверенные vs Неуверенные прогнозы

Система использует **два критерия** для оценки уверенности:

#### 1. Сходимость моделей

**Уверенный прогноз (Convergent):**
- Модели предсказывают схожие значения
- Разброс между лучшей и худшей моделью < 0.3 п.п.
- **Пример:** Ridge: 0.45%, NGBoost: 0.48%, Huber: 0.46% → **Уверенно**

**Неуверенный прогноз (Divergent):**
- Модели предсказывают сильно разные значения
- Разброс > 0.6 п.п.
- **Пример:** Ridge: 0.30%, Prophet: 0.80%, SARIMA: 0.20% → **Неуверенно**

#### 2. Историческая точность

**Уверенный:**
- MAE за последние 3 месяца < 0.4
- Нет KPI violations в последние 6 месяцев
- Ошибка уменьшается (тренд к улучшению)

**Неуверенный:**
- MAE > 0.5 в последние месяцы
- Были KPI violations
- Ошибка растёт (тренд к ухудшению)

### Как читать прогноз на вкладке "Прогноз"

```
┌─────────────────────────────────────────────────────┐
│  Прогноз на Февраль 2026: +0.42%            │
│  Диапазон: +0.30% ... +0.55%                │
│  Уверенность: ВЫСОКАЯ                        │
│                                              │
│  Разброс моделей: 0.25 п.п. (узкий)          │
│  MAE за 3 мес: 0.32 (хорошо)               │
└─────────────────────────────────────────────────────┘
```

**Интерпретация:**
- **+0.42%** — ожидаемый рост инфляции в феврале
- **Диапазон** — большинство моделей предсказывают в этом коридоре
- **Уверенность: ВЫСОКАЯ** — доверяйте этому прогнозу
- **Разброс < 0.3** — модели согласны между собой

### Что делать при неуверенном прогнозе?

1. **Проверьте вкладку "Экзогенные"** — нет ли аномальных значений в USD/Ki/Brent
2. **Посмотрите вкладку "Weekly"** — есть ли ценовые аномалии (alerts)
3. **Сравните с h=2** — если прогнозы h=1 и h=2 похожи, значит тенденция устойчивая
4. **Используйте консервативный сценарий** — берите середину диапазона или худшее значение

### Сценарный анализ

На вкладке **"Экзогенные"** можно протестировать влияние макро-факторов:

| Фактор | Параметр | Влияние на инфляцию |
|---------|-----------|---------------------|
| Курс доллара | +10% | +0.5...+1.0 п.п. (через 2-3 мес) |
| Ключевая ставка | +1 п.п. | -0.2...-0.5 п.п. (через 6-12 мес) |
| RUONIA | +1 п.п. | -0.1...-0.3 п.п. (через 3-6 мес) |

**Примечание:** Влияние нелинейное и асимметричное (повышение ставки действует сильнее).

## Часто задаваемые вопросы (FAQ)

### Q1: Почему прогнозы разных моделей отличаются?

**A:** Каждая модель использует разные подходы:
- **Ridge:** Линейная регрессия + авторегрессия
- **NGBoost:** Нелинейный бустинг с вероятностями
- **Prophet:** Тренды + сезонность
- **BVAR:** Векторная авторегрессия (взаимосвязь переменных)

Различия нормальны! Ансамбль усредняет эти прогнозы.

### Q2: Какой прогноз использовать для принятия решений?

**A:** Используйте **ансамбль** (чёрная линия на вкладке "Прогноз"):
- Он стабилен в долгосрочной перспективе
- Объединяет сильные стороны всех моделей
- Исторически показал низкий MAE

**Исключения:**
- Для nowcasting (текущий месяц) → используйте **Weekly**
- Для анализа драйверов → смотрите вкладку "История"

### Q3: Что делать если прогноз "неуверенный"?

**A:** Неуверенность = высокий разброс моделей + плохая историческая точность.

**Действия:**
1. Проверьте вкладку "Weekly" → нет ли аномалий
2. Сравните с прошлым месяцем → тренд или аномалия?
3. Посмотрите вкладку "Экзогенные" → разумные ли значения USD/Ki/Brent
4. Используйте консервативный сценарий середины диапазона

### Q4: Как интерпретировать MAE?

**A:** MAE — средняя ошибка прогноза.

| MAE | Оценка |
|-----|--------|
| < 0.3 | Отлично |
| 0.3 - 0.4 | Хорошо |
| 0.4 - 0.5 | Удовлетворительно |
| > 0.5 | Требует внимания |

**Пример:** MAE = 0.35 означает, что прогноз в среднем ошибается на 0.35 п.п.

### Q5: Что такое KPI Violations?

**A:** Это месяцы, когда ошибка прогноза превысила 0.5 п.п.

**Почему 0.5?** Это порог, после которого ошибка становится критической для бизнес-решений.

**Цель:** < 10% месяцев с нарушениями (менее 1-2 в год).

### Q6: Почему нужно смотреть h=1, h=2, h=12?

**A:** Разные горизонты → разные задачи:

- **h=1** — оперативные решения (на следующий месяц)
- **h=2** — квартальное планирование
- **h=12** — годовой бюджет, стратегия

Модели по-разному работают на разных горизонтах! Например, NGBoost лучший на h=2, но хуже на h=1.

### Q7: Как часто обновляется система?

**A:**
- **Данные:** Ежемесячно (после публикации Росстата)
- **Модели:** Перенастраиваются автоматически при новых данных
- **Прогнозы:** Пересчитываются при каждом обновлении данных

### Q8: Что такое "Weekly Nowcasting"?

**A:** Nowcasting — это оценка текущей инфляции ДО официальной публикации.

**Как работает:**
1. Берём недельные цены по 155 продуктам
2. Агрегируем в месячный сигнал
3. Корректируем с учётом календаря и весов

**Точность:** MAE 0.043% (значительно лучше месячных моделей для текущего месяца!)

### Q9: Как понять что "система работает правильно"?

**A:** Проверьте 3 критерия:

1. **MAE < 0.5** на вкладке "Бэктест h=1"
2. **KPI violations < 2** за последние 12 месяцев
3. **Ансамбль в топ-5** по стабильности

Если все три выполнены → система работает хорошо.

### Q10: Можно ли доверять прогнозу на 12 месяцев вперёд?

**A:** С осторожностью!

- **h=1** (1 месяц): Высокая точность (MAE ~0.3)
- **h=6** (6 месяцев): Средняя точность (MAE ~0.35)
- **h=12** (12 месяцев): Низкая точность (MAE ~0.4)

**Рекомендация:**
- Для решений на 1-2 месяца — доверяйте h=1
- Для планирования на полгода — используйте с запасом
- Для года — только для понимания тренда, не для точных цифр

### Q11: Что такое "Volatility Alerts"?

**A:** Это предупреждения о резких скачках цен на уровне продуктов.

**Критерии:**
- **Critical:** > 3σ (крайне редко, ~1% случаев)
- **Warning:** > 2σ (редко, ~5% случаев)

**Когда смотрите:**
- Weekly alerts → проблема в текущем месяце
- Если много критических → возможен шок (как 2014 или 2022)

### Q12: Какой вкладке доверять больше всего?

**A:** Приоритеты для бизнес-пользователей:

1. **📈 Прогноз** — основной прогноз (ансамбль)
2. **📊 Бэктест h=1** — точность системы (главный КПЭ)
3. **📈 Weekly** — nowcast текущего месяца
4. **🧠 История** — анализ драйверов инфляции

Остальные вкладки — для аналитиков и разработчиков.

### Q13: Что делать если прогноз расходится с фактом?

**A:** Это нормально! Шоки и аномалии неизбежны.

**Проверьте:**
1. Было ли нарушением KPI (ошибка > 0.5)?
2. Если да → какая причина?
   - Шок (резкое изменение USD/Ki/Brent)?
   - Сезонность (новогодний спрос, урожай)?
   - Ошибка в данных?

3. Если нет → система работает в норме (шум неизбежен)

### Q14: Можно ли использовать систему для других регионов?

**A:** В текущем виде — нет.

Система настроена на специфику КБР:
- Структура потребления (веса продуктов)
- Сезонные паттерны (урожай, туризм)
- Макро-связи (USD/Ki/Brent)

Для другого региона нужна перенастройка моделей и данных.

2. **Отслеживайте аномалии** — Weekly alerts помогут заблаговременно
3. **Используйте все горизонты** — h=1, h=2, h=12 для разных задач

## Глоссарий

| Термин | Описание |
|---------|----------|
| **Ансамбль** | Комбинация прогнозов нескольких моделей для улучшения точности |
| **Backtest** | Проверка точности модели на исторических данных |
| **Exogenous** | Внешние переменные (USD, Ki, Brent), не входящие в ИПЦ |
| **Forecast** | Прогноз будущих значений |
| **h=1, h=2, h=12** | Горизонт прогноза (1, 2, 12 месяцев) |
| **KPI** | Ключевой показатель эффективности (MAE < 0.5) |
| **MAE** | Mean Absolute Error — средняя абсолютная ошибка |
| **Nowcasting** | Оценка текущего значения (до официальной публикации) |
| **Shock** | Резкое, неожиданное изменение (например, +10% к доллару) |
| **Subcomponent** | Субкомпонент ИПЦ (например, "Мясопродукты", "ЖКХ") |
| **Volatility** | Волатильность — мера изменчивости цен |
| **YoY** | Year-over-Year — рост за год |
