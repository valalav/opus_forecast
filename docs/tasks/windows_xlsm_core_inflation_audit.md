# Задача: аудит Excel-инструмента расчета устойчивой инфляции

## Цель

Проверить `.xlsm`-инструмент расчета устойчивой инфляции и понять, почему показатели устойчивой инфляции сильно скачут по месяцам.

Нужно определить, являются ли скачки:

1. экономически объяснимыми;
2. следствием методики;
3. ошибкой Excel/VBA/сводных/весов/формул.

## Рабочая среда

Работать в Windows с установленным Microsoft Excel, так как файл содержит VBA-макросы, сводные таблицы, CubeFields/OLAP и, возможно, модель данных.

## Исходные файлы

Основной файл:

- `Расчет_устойчивой_инфляции.xlsm`

Связанный источник:

- `database.xlsx`

Если фактические имена отличаются, зафиксировать точные имена и пути в отчете.

## Важное ограничение

Не менять исходные файлы без создания копии.

Перед началом создать рабочую копию:

- `Расчет_устойчивой_инфляции_AUDIT_YYYY-MM-DD.xlsm`
- `database_AUDIT_YYYY-MM-DD.xlsx`, если потребуется

Все изменения, тесты и макросы запускать только на копии.

## Что проверить

### 1. Инвентаризация файла

Составить список:

- всех листов;
- скрытых и very hidden листов;
- всех макросов/VBA-модулей;
- всех именованных диапазонов;
- всех таблиц Excel;
- всех сводных таблиц;
- всех внешних подключений;
- всех Power Query / Model / Data Model подключений, если есть;
- всех внешних ссылок на другие файлы.

Результат сохранить в отдельный лист `AUDIT_inventory` или в отдельный файл `audit_inventory.xlsx`.

### 2. Проверка макроса загрузки данных

Особенно проверить макрос:

```vba
Подгрузка_ИПЦ_если_по_умолчанию_yoy
```

Проверить и описать:

- какие листы он заполняет;
- какие диапазоны копирует из `database.xlsx`;
- какие поля сводной использует;
- где используется `MoM2`;
- где используется `YoY2`;
- какие `Item_type` выбираются;
- очищаются ли старые фильтры перед установкой новых;
- очищаются ли старые данные на целевых листах перед вставкой;
- не остаются ли старые данные справа/снизу после вставки нового диапазона;
- не смешиваются ли MoM и YoY в одном расчете.

Особенно обратить внимание на строки вида:

```vba
CubeFields.GetMeasure "[trnst_regional].[MoM2]", xlSum, "Сумма по столбцу MoM2"
```

Проверить, не суммируются ли индексы там, где нужна весовая агрегация.

### 3. Проверка сводных таблиц

Для каждой сводной таблицы, которую использует макрос, зафиксировать:

- имя сводной;
- источник данных;
- поля строк;
- поля столбцов;
- поля значений;
- примененные фильтры;
- выбранные `Item_type`;
- включены ли промежуточные итоги/subtotals;
- включены ли grand totals;
- есть ли пустые строки/столбцы внутри выгружаемого диапазона.

Проверить, что диапазон, копируемый через:

```vba
Range("A5").Select
Range(Selection, Selection.End(xlToRight)).Select
Range(Selection, Selection.End(xlDown)).Select
```

действительно покрывает только нужную таблицу и не обрезает/не захватывает лишнее.

### 4. Проверка структуры Item_type

Определить, что означают значения:

- `Item_type = 1`
- `Item_type = 3`
- `Item_type = 5`
- `Item_type = 6`

Проверить, не смешиваются ли в одном расчете:

- общий ИПЦ;
- агрегаты;
- субкомпоненты;
- микрокомпоненты;
- служебные показатели вроде "без плодоовощей".

Если смешиваются разные уровни иерархии, это может приводить к скачкам и двойному счету.

### 5. Проверка весов

Для каждого показателя устойчивой инфляции проверить:

- из какого листа берутся веса;
- за какой месяц/год берутся веса;
- меняются ли веса по месяцам;
- совпадает ли сумма весов с ожидаемой;
- перенормируются ли веса после исключения компонентов;
- не попадают ли исключенные компоненты в числитель или знаменатель;
- нет ли месяцев, где сумма весов резко меняется.

Отдельно проверить листы/таблицы, связанные с БИПЦ:

- список исключаемых товаров;
- вес исключаемых товаров;
- итоговый вес оставшейся корзины;
- формулы `INDEX/MATCH`, подтягивающие веса;
- корректность выбора периода весов.

### 6. Проверка формул устойчивой инфляции

Найти все итоговые показатели устойчивой инфляции и для каждого описать формулу:

- название показателя;
- лист;
- ячейка;
- формула;
- исходные листы/диапазоны;
- используется MoM или YoY;
- используется индекс или прирост;
- используется ли сезонная очистка;
- используются ли веса;
- как обрабатываются исключения;
- как обрабатываются пустые значения;
- как обрабатываются ошибки `#N/A`, `#VALUE!`, `#DIV/0!`.

Важно проверить, не считается ли показатель как простое среднее или сумма индексов без весов.

### 7. Проверка скачков

Выбрать последние 24-36 месяцев и построить таблицу:

- дата;
- headline CPI MoM;
- headline CPI YoY;
- каждый показатель устойчивой инфляции;
- изменение показателя к предыдущему месяцу;
- сумма используемых весов;
- число компонентов в расчете;
- топ-10 положительных вкладов;
- топ-10 отрицательных вкладов;
- список исключенных компонентов.

Для месяцев с резкими скачками определить причину:

- скачок одного/нескольких компонентов;
- изменение состава корзины;
- изменение весов;
- переход MoM/YoY;
- ошибка диапазона;
- старые данные на листе;
- некорректное обновление сводной;
- техническая ошибка формулы.

### 8. Независимая перепроверка расчета

Сделать независимый расчет хотя бы для 3-5 проблемных месяцев вручную или отдельным простым Excel/Python-скриптом.

Минимальная формула для проверки:

```text
Core_MoM = SUM(weight_i * mom_i) / SUM(weight_i)
```

где `i` - только компоненты, которые должны входить в показатель устойчивой инфляции.

Если исходные данные в виде индексов `100.xx`, сначала переводить в прирост:

```text
mom_growth_i = index_i - 100
```

Затем агрегировать приросты по весам.

Проверить отдельно:

```text
core_index = 100 + Core_MoM
```

Не суммировать сами индексы `100.xx` без нормализации.

### 9. Предложения по исправлению

По результатам аудита предложить конкретные исправления.

Ожидаемые типы исправлений:

- перед установкой фильтров делать `ClearAllFilters`;
- очищать целевые листы перед вставкой новых данных;
- заменить `Select/End(xlDown)` на явное определение диапазона сводной;
- использовать `PivotTable.TableRange1` или `TableRange2`;
- разделить загрузку MoM и YoY на два независимых макроса;
- явно подписать все листы `mom`, `yoy`, `index`, `growth`;
- запретить смешение уровней `Item_type`;
- добавить контроль суммы весов;
- добавить контроль числа компонентов;
- добавить лист проверки `AUDIT_checks`;
- добавить предупреждение, если сумма весов вне допустимого диапазона;
- добавить предупреждение, если показатель скачет больше заданного порога.

## Что нужно получить на выходе

### 1. Отчет

Файл:

- `audit_report_core_inflation_xlsm.md` или `.docx`

В отчете должны быть разделы:

1. Краткий вывод.
2. Найденные причины скачков.
3. Критичные ошибки расчета, если есть.
4. Методологические проблемы, если есть.
5. Технические проблемы Excel/VBA.
6. Проверка MoM/YoY.
7. Проверка весов.
8. Проверка Item_type.
9. Примеры проблемных месяцев.
10. Рекомендации по исправлению.
11. Что было проверено, а что осталось непроверенным.

### 2. Таблица диагностики

Файл:

- `audit_core_inflation_diagnostics.xlsx`

Листы:

- `inventory`
- `macros`
- `pivot_tables`
- `connections`
- `named_ranges`
- `core_indicators`
- `weights_check`
- `mom_yoy_check`
- `jump_months`
- `top_contributors`
- `manual_recalc`

### 3. Исправленная копия, если возможно

Если ошибки очевидны и исправимы без изменения методики, сделать копию:

- `Расчет_устойчивой_инфляции_FIXED_YYYY-MM-DD.xlsm`

В ней:

- не ломать исходную структуру;
- оставить старые листы;
- добавить лист `AUDIT_checks`;
- добавить комментарии к измененным макросам;
- сохранить совместимость с Excel.

### 4. Краткая записка для пользователя

Отдельно дать короткий вывод на 5-10 предложений:

- можно ли доверять текущим показателям;
- почему они скачут;
- что нужно исправить первым;
- стоит ли переносить расчет из Excel в Python/СИРЕНА.

## Контрольные вопросы, на которые должен ответить агент

1. Используется ли где-либо сумма индексов вместо весовой агрегации приростов?
2. Не смешиваются ли MoM и YoY?
3. Очищаются ли фильтры сводных перед новой загрузкой?
4. Очищаются ли старые данные на целевых листах?
5. Не смешиваются ли разные уровни `Item_type`?
6. Перенормируются ли веса после исключения шумных компонентов?
7. Стабильна ли сумма весов по месяцам?
8. Какие месяцы дают максимальные скачки устойчивой инфляции?
9. Какие компоненты дают эти скачки?
10. Это экономический эффект или ошибка расчета?

## Главный принцип работы

Не начинать с переписывания файла. Сначала доказать, где именно рождается скачок: в данных, в сводной, в весах, в формуле или в методике.
